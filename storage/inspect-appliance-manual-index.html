Diagnosi appliance_manuals

Questa pagina non modifica il database. Copia una query SQL che mostra le colonne reali della tabella e la definizione dell’indice appliance_manuals_one_primary_idx.

select
  c.column_name,
  c.data_type,
  c.is_nullable,
  c.column_default
from information_schema.columns c
where c.table_schema = 'public'
  and c.table_name = 'appliance_manuals'
order by c.ordinal_position;

select
  schemaname,
  tablename,
  indexname,
  indexdef
from pg_indexes
where schemaname = 'public'
  and tablename = 'appliance_manuals'
  and indexname = 'appliance_manuals_one_primary_idx';
