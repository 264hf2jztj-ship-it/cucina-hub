Diagnostica vincolo tipo manuali

Questa pagina non modifica Supabase. Copia una query in sola lettura per mostrare la definizione reale del vincolo manuals_type_allowed.

select
  c.conname as constraint_name,
  pg_get_constraintdef(c.oid) as constraint_definition
from pg_constraint c
join pg_class t on t.oid = c.conrelid
join pg_namespace n on n.oid = t.relnamespace
where n.nspname = 'public'
  and t.relname = 'manuals'
  and c.conname = 'manuals_type_allowed';

Esegui la query nel Supabase SQL Editor e inviami il risultato.
