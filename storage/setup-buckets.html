Macrostep 6.2 — Bucket privati

Questa pagina mostra lo script SQL idempotente da eseguire nel Supabase SQL Editor.

Operazione amministrativa: la creazione dei bucket richiede privilegi SQL e non viene eseguita dal browser con la chiave anonima.

  1. Premi Copia SQL.
  2. Apri Supabase → SQL Editor → New query.
  3. Incolla ed esegui.
  4. Controlla che il risultato mostri quattro righe e public = false per tutte.
