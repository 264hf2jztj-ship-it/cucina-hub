Comando Rapido “Cucina Hub Calendario”

Questa configurazione si esegue una sola volta. Dopo, il pulsante AGGIUNGI DIRETTAMENTE del Wizard creerà gli appuntamenti senza passare da Mail o dal file .ics.

APRI UN NUOVO COMANDO RAPIDO TORNA AL WIZARD

Nome obbligatorio: Cucina Hub Calendario

Azioni da inserire

1. Rinomina il comando
Usa esattamente Cucina Hub Calendario.
2. Leggi gli appunti
Aggiungi Ottieni dizionario dagli appunti. Cucina Hub copia il JSON negli appunti prima di aprire il comando. Su iPad non usare “Ottieni dizionario dall’input”, perché il valore può risultare vuoto.
3. Estrai l’elenco degli eventi
Aggiungi Ottieni valore dizionario e usa la chiave minuscola events.
4. Ripeti per ogni evento
Aggiungi Ripeti con ogni elemento usando l’elenco ottenuto nel passaggio precedente.
5. Dentro “Ripeti”, estrai i campi
Dal Elemento ripetuto ricava i campi minuscoli title, start, end e notes. Per start ed end usa poi Ottieni date dall’input.
6. Crea l’appuntamento
Aggiungi Aggiungi nuovo evento e collega: titolo = title, inizio = data ottenuta da start, fine = data ottenuta da end, note = notes. Seleziona il calendario iCloud, imposta per ora un avviso fisso di 5 minuti e disattiva Mostra foglio di composizione.
7. Conferma finale
Dopo “Fine ripetizione”, aggiungi Mostra notifica con il testo “Eventi Cucina Hub aggiunti al Calendario”.
Nota sugli appunti: premendo il test o l’aggiunta diretta, il contenuto attuale degli appunti viene sostituito temporaneamente dal JSON della timeline. La prima azione del comando deve quindi leggere direttamente il dizionario dagli Appunti.

Campi ricevuti dal Wizard

title
Titolo dell’appuntamento
start
Data e ora iniziale ISO
end
Data e ora finale ISO
notes
Istruzione operativa
alert
Anticipo disponibile per una futura gestione dinamica

Prova il collegamento

Il test copia negli appunti un JSON con due appuntamenti temporanei, programmati fra circa 10 e 20 minuti, quindi avvia il comando.

Prima completa i sette passaggi sopra.
